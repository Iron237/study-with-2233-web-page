# 和 2233 一起自习

带有房间动画、音乐播放器、专注计时、待办与桌宠互动的网页项目。

## 启动

安装 Node.js 22 或更高版本，在项目目录执行 `npm start`，打开 http://127.0.0.1:8874/ 。服务器部署可通过 `HOST`、`PORT` 设置监听地址和端口。

## 功能

- 动态房间、歌曲与整张歌单的播放进度、音量调节。
- 设定时长或不限时，记录本轮、今日与累计专注时间。
- 个人待办事项。
- 2233 桌宠组件、摸摸、拖动和姿势切换。
- 分辨率适配、全屏和反馈页面。
