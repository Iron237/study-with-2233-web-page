# 和 2233 一起自习

带有房间动画、音乐播放器、专注计时、待办与桌宠互动的网页项目。

## 启动

安装 Node.js 22 或更高版本，在项目目录执行 `npm start`，打开 http://127.0.0.1:8874/ 。无需第三方 npm 依赖。服务器部署可通过 `HOST`、`PORT` 设置监听地址和端口。

## 功能

- 动态房间、歌曲与整张歌单的播放进度、音量调节。
- 默认专注，支持设定时长或不限时，记录本轮、今日与累计专注时间。
- 22、33 固定待办，以及个人待办。
- 22:33 桌宠自动出现、摸摸、拖动和姿势切换。
- 分辨率适配、全屏和反馈页面。

音乐使用网易云公开音频地址，需要联网。本仓库不是完整离线 Wallpaper Engine 发行包。

## 公开对白边界

只公开 `content/basic-dialogue.json` 的 **12 组基础对白**。所有场景复用这份内容，不包含私人版本的自定义对白与推荐资源。后续新增对白默认不发布。

`public/dialogue.js` 为兼容运行时结构，内容只能来自这 12 组；`content/pet-content.json` 保存角色素材映射及基础对白组，公开推荐库为空。

不要把私人项目直接复制进仓库。使用维护者的白名单导出流程；新增文件默认被忽略，审查后才加入 `public-manifest.json` 和 `.gitignore`。运行 `npm test` 验证公开内容。可执行 `git config core.hooksPath .githooks` 启用提交和推送前检查。检查不能替代人工审查，尤其是图片和媒体素材。

## 数据

专注记录写入运行目录 `var/`，个人待办与偏好使用浏览器本地存储。`var/`、日志、凭据与环境文件不进入版本控制。部署时可设置 `FOCUS_DATA_DIR` 和 `CDN_BASE`；本仓库不含维护者服务器配置。
